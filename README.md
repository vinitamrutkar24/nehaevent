# Neha Event

Neha Event is a modern event management and decoration website designed to showcase elegant event planning services, creative decorations, and memorable celebration experiences.

## Services

* Wedding Event Planning
* Birthday Decoration
* Corporate Events
* Engagement Ceremonies
* Stage Decoration
* Photography & Videography
* Catering Arrangements
* Custom Theme Events

## Website Features

* Responsive modern design
* Gallery showcase
* Product and service listings
* Contact inquiry form
* Mobile-friendly interface

## Technologies Used

* HTML5
* CSS3
* JavaScript
* GitHub Pages Hosting
